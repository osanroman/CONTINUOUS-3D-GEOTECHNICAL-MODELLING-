GEOTECHNICAL UNIT ANALYSIS

This repository contains the Python notebooks and input datasets used for the
analysis of geotechnical parameters and the identification of geotechnical
units.

# REPOSITORY CONTENT

The repository contains the following parameter-specific notebooks and their
corresponding input datasets:

* w.ipynb              -> w_ok
* Vs.ipynb             -> Vs_ok
* N.ipynb              -> SPT_ok
* qc.ipynb             -> CPT_FIN
* fs.ipynb             -> CPT_FIN
* u2.ipynb             -> CPT_FIN

The CPT-derived parameters — tip resistance (qc), friction (fs), and pore
pressure (u2) — are processed using the common CPT_FIN dataset.

The final clustering analysis is performed using:

* FIN_Clusters.ipynb  -> Variables

# WORKFLOW

The analysis consists of independent parameter-specific processing followed
by the consolidation of the extrapolated results and the final clustering of
geotechnical units.

1. PARAMETER-SPECIFIC PROCESSING

---

Each parameter is processed independently using its corresponding Python
notebook and input dataset.

The parameter-specific workflows are:

* w_ok -> w.ipynb -> extrapolated water-content data
* Vs_ok -> Vs.ipynb -> extrapolated wave-velocity data
* SPT_ok -> N.ipynb -> extrapolated SPT-N data
* CPT_FIN -> qc.ipynb -> extrapolated tip-resistance data (qc)
* CPT_FIN -> fs.ipynb -> extrapolated friction data (fs)
* CPT_FIN -> u2.ipynb -> extrapolated pore-pressure data (u2)

These processing steps are independent and can be performed separately.

2. CONSOLIDATION OF EXTRAPOLATED DATA

---

The extrapolated results generated by the parameter-specific notebooks are
combined into a single consolidated dataset.

This consolidated dataset contains the extrapolated information from all
analyzed parameters and is used as the input for the final clustering
analysis.

The consolidated dataset is represented by the Variables dataset.

Due to its large file size, the Variables dataset is NOT included in this
repository. It must be generated by combining the extrapolated results from
the parameter-specific processing.

3. GEOTECHNICAL UNIT CLUSTERING

---

The consolidated dataset generated from the parameter-specific results is
used as input for FIN_Clusters.ipynb.

FIN_Clusters.ipynb performs the clustering analysis and generates the
resulting geotechnical units.

# OVERALL WORKFLOW

```
                     ┌── w_ok ────────→ w.ipynb ────────→ Extrapolated w
                     │
                     ├── Vs_ok ───────→ Vs.ipynb ───────→ Extrapolated Vs
                     │
                     ├── SPT_ok ──────→ N.ipynb ────────→ Extrapolated N
                     │
                     ├── CPT_FIN ─────→ qc.ipynb ───────→ Extrapolated qc
                     │
                     ├── CPT_FIN ─────→ fs.ipynb ───────→ Extrapolated fs
                     │
                     └── CPT_FIN ─────→ u2.ipynb ───────→ Extrapolated u2
                                                                  │
                                                                  │
                                                                  ▼
                                                       Variables dataset
                                                      (Consolidated data)
                                                                  │
                                                                  ▼
                                                        FIN_Clusters.ipynb
                                                                  │
                                                                  ▼
                                                         Geotechnical units
```

# NOTES

* All analysis notebooks are written in Python.
* Each parameter-specific notebook uses its corresponding input dataset.
* The CPT_FIN dataset is shared by qc.ipynb, fs.ipynb, and u2.ipynb.
* The parameter-specific analyses are independent and can be performed
  separately.
* Each parameter-specific notebook generates extrapolated data that
  contributes to the consolidated dataset.
* The Variables dataset contains the consolidated extrapolated results from
  all analyzed parameters.
* Due to its large file size, the Variables dataset is not included in this
  repository.
* The consolidated dataset must be generated before running
  FIN_Clusters.ipynb.
* FIN_Clusters.ipynb uses the consolidated dataset as input to generate the
  final geotechnical units.

# REPRODUCIBILITY

To reproduce the analysis:

1. Clone or download this repository.
2. Ensure that each input dataset is available in the expected location.
3. Run the parameter-specific notebooks independently:

   * w.ipynb
   * Vs.ipynb
   * N.ipynb
   * qc.ipynb
   * fs.ipynb
   * u2.ipynb
4. Collect the extrapolated results generated by each notebook.
5. Combine the extrapolated results into the consolidated Variables dataset.
6. Provide the Variables dataset as input to FIN_Clusters.ipynb.
7. Run FIN_Clusters.ipynb to obtain the resulting geotechnical units.
